Anyway, now that 0.16.0 is out I don't have any excuse to remain a lurker on the [Zig subreddit](https://www.reddit.com/r/Zig/) and start building. One condition that I have put up for myself in this journey is _NO Vibecoding_. I can use AI to brainstorm my project implementation plans but my neovim setup doesn't have any AI tool config, not even autocomplete. Sounds regressive but I have come to realise that vibecoding in its current stage is destroying the "coding aptitude" which is especially needed in lower level language. And, it can be argued that vibecoding goes against Zig's whole motto of giving as much control as possible.

I have tried playing around with Zig before using the [ziglings](https://codeberg.org/ziglings/exercises) project that aims to teach zig with small sets of exercises. To be honest, I got bored of spending too much time on meaningless exercises and more over I didn't learn much from it.
